## 🎯 What It Does

Text Burn Neon animates every character independently through a multi-stage ignition sequence:

1. Flicker — characters rapidly appear and disappear like unstable heat.
2. Burn — fiery color and layered glow build around each character.
3. Hot — the character reaches a bright, intense peak.
4. Fade — the heat settles into the final text color.
5. Loop — optionally repeat the complete sequence continuously.

Randomized character timing gives every ignition a dynamic, organic feel instead of a rigid one-by-one transition.
